# 반드시 지킬 것
- 기호나 약어(MAE, RMSE, R² 등)는 처음 나올 때 한 줄로 설명하기
- 데이터 증강(합성 행 · 행 복제 · 정답에 잡음 넣기)은 쓰지 않기
- 전처리(표준화 · 인코딩)는 Pipeline 안에서 학습 데이터에만 fit (데이터 누수 금지)
- 여유분 · 하이퍼파라미터는 학습 데이터의 교차검증으로만 고르기 (시험 데이터는 마지막에 한 번만)
- R² 하나만 보고하지 않기: MAE · RMSE · 고액(상위 10%) MAE · 과소 추정 비율을 기준선과 함께
- 로그 변환을 썼다면 예측을 달러로 되돌려 평가하기
- 코드는 Google Colab 에서 바로 실행되게, random_state=42 고정, 내가 바꿀 줄에는 # [변경] 주석

용어 사전Glossary

비유로 먼저, 뜻은 그다음.

선형 회귀
직선 긋기. 특성마다 금액을 더하는 모델. 계수 = 특성 1단위의 금액 효과.
릿지
브레이크 단 직선. 계수가 너무 커지지 않게 벌점(alpha)을 주는 선형 회귀.
의사결정나무
스무고개. 예/아니오 질문을 이어 금액 구간을 나눈다. 모양은 계단.
KNN
비슷한 이웃의 평균. 가장 가까운 k명의 금액 평균으로 답한다.
그래디언트 부스팅
틀린 만큼 고쳐 쌓기. 작은 나무를 차례로 더해 앞 나무의 오차를 줄인다.
과적합
기출 문제만 외우기. 학습 오차는 줄고 새 데이터 오차는 커지는 상태.
하이퍼파라미터
모델의 다이얼. 깊이 · 이웃 수 · 나무 개수처럼 사람이 정하는 설정.
교차검증
돌아가며 모의고사. 학습 데이터를 5조각으로 나눠 한 조각씩 검증. 시험 데이터는 건드리지 않는다.
상호작용
둘이 만나면 달라지는 효과. 흡연 효과가 BMI 에 따라 달라지는 것. 직선은 따로 넣어 줘야 한다.
