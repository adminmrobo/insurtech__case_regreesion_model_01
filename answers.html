모두에게 평균만: 평균의 함정해설형

1편 페이지의 교육자 안내로 돌아가기

확인 문제 (4개)

문제 1

Q1. 시험 268명 모두에게 학습 평균 $13,250 을 답했더니 예측 합계가 실제 합계와 −1.1% 차이였습니다. 이 기준선에 대한 설명으로 맞는 것은?

  1. 합계가 거의 맞으니 좋은 견적 모델이다
    오해: 합계는 평균의 성질로 저절로 맞습니다. 사람마다 평균 $9,151 씩 틀립니다.
  2. 합계는 맞아도 한 사람당 평균 $9,151 틀리고, R² 는 0 근처다 ✔ 정답
  3. R² 가 1 에 가깝다
    오해: R² 의 기준점이 바로 ‘평균만 말하기’라서 기준선의 R² 는 0 근처(−0.0001)입니다.

해설 기준선 MAE $9,151, R² −0.0001. 고액 상위 10% 고객에게는 평균 $28,371 씩 틀립니다. 합계 차이 −1.1% 는 평균을 썼기 때문에 생기는 성질입니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

문제 2

Q2. ‘흡연 여부별 평균’ 규칙은 MAE 를 $9,151 → $5,750 으로 줄였지만 과소 추정 비율은 31.7% → 44.8% 로 늘었습니다. 올바른 해석은?

  1. 과소 추정이 늘었으니 기준선보다 나쁜 규칙이다
    오해: 과소 추정 ‘비율’만 늘었고 금액 오차는 크게 줄었습니다. 고액 MAE 도 $28,371 → $10,123 입니다.
  2. 평균 오차와 고액 오차는 크게 줄었지만, 적게 잡는 사람이 늘었으므로 과소 추정의 비용을 따로 따져야 한다 ✔ 정답
  3. MAE 하나만 보면 충분하다
    오해: 같은 MAE 라도 적게 잡는지 많이 잡는지에 따라 보험사 비용이 다릅니다(4편).

해설 흡연 규칙은 비흡연자 1,063명 대부분에게 비흡연자 평균($8,461)을 주는데, 비흡연자 중앙값은 $7,346 이라 많은 사람에게 조금 많이, 일부 고액 비흡연자에게는 적게 줍니다. 숫자 하나로 판단하지 않습니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

문제 3

Q3. 다음 중 MAE 의 뜻으로 맞는 것은?

  1. 한 사람당 실제와 예측이 평균 몇 달러 차이 나는가 (부호 무시) ✔ 정답
  2. 예측 합계와 실제 합계의 차이
    오해: 그것은 합계 차이입니다. 기준선도 −1.1% 로 작게 나옵니다.
  3. 평균만 말하기보다 제곱 오차를 몇 % 줄였나
    오해: 그것은 R² 입니다.

해설 MAE = mean(|실제 − 예측|). 최종 모델은 $2,470, 기준선은 $9,151 입니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

문제 4

Q4. 나이 × 의료비 평면에서 띠가 세 줄로 보입니다. 흡연 × 비만 버튼을 누르면 맨 위 띠는 대부분 ‘흡연자이면서 BMI 30 이상’입니다. 이것이 말해 주는 것은?

  1. 흡연자는 모두 비만이다
    오해: 흡연자 274명 중 BMI 30 미만도 129명입니다. 이들은 가운데 띠에 있습니다.
  2. 나이 하나만으로는 정보가 모자라고, 흡연(그리고 흡연 × 비만) 같은 숨은 열쇠가 금액을 크게 가른다 ✔ 정답
  3. 흡연 열은 민감하니 빼야 한다
    오해: 흡연은 의료비의 가장 강한 단서입니다. 다만 성별·지역처럼 쓰면 안 되는 특성은 6편에서 따로 점검합니다.

해설 흡연자 평균 $32,050 은 비흡연자 $8,441 의 3.8배입니다. 흡연자 중 BMI 30 이상 145명의 평균은 $41,558 로 맨 위 띠를 이룹니다. 5편 대리모델의 첫 질문도 ‘흡연자인가?’입니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

강의 멘트

기준선

도입 오늘은 모두에게 평균만 말하는 ‘아무것도 안 하는 모델’부터 봅니다.

핵심 버튼을 누르기 전에 묻습니다. 모두에게 평균을 말하면 예측 합계는 실제와 몇 % 차이 날까요?

흔한 오해 흔한 오해: “합계가 맞으면 좋은 모델”. 합계는 평균의 성질로 저절로 맞습니다(−1.1%). 한 사람당 $9,151 씩 틀립니다.

정리 정리: R² 의 0 점이 곧 기준선이다. 모든 점수를 기준선과 함께 읽는다.

좌표 평면

도입 나이 × 의료비 평면을 펼치고, 띠가 몇 줄인지 세어 보게 합니다.

핵심 흡연 버튼을 누르기 전에, 맨 위 띠의 사람들이 어떤 공통점이 있을지 예측하게 합니다.

흔한 오해 흔한 오해: “흡연자는 다 비만”. 흡연자 274명 중 129명은 BMI 30 미만이고 가운데 띠에 있습니다.

정리 정리: 평면에 없는 열(흡연)이 금액을 가른다 = 숨은 열쇠. 5편에서 회수.

볼 숫자

도입 MAE · RMSE · R² · 고액 MAE 네 잣대를 고정합니다.

핵심 핵심: MAE 는 주지표, R² 는 평균 대비 개선, 고액 MAE 는 꼬리의 오차.

흔한 오해 흔한 오해: “R² 0.86 이면 거의 다 맞힌다”. 최종 모델도 19.4% 를 과소 추정합니다.

정리 정리: 숫자 하나로 판단하지 않는다. 주지표 + 보조 지표 + 기준선을 한 표에.

문제 1

Q1. charges 를 IQR × 1.5 로 걸면 139명이 이상치로 표시됩니다. 이 139명을 지우면 생기는 일로 맞는 것은?

  1. 데이터가 깨끗해질 뿐 모델에는 영향이 없다
    오해: 학습에서 고액을 본 적 없는 모델은 시험의 고액 고객을 낮게 부릅니다. 최종 모델의 고액 MAE 가 $3,612 → $14,379 로 커집니다.
  2. 걸린 사람의 97.8%가 흡연자라, 숨은 열쇠(흡연)의 신호와 고액 꼬리를 함께 잃는다 ✔ 정답
  3. 평균이 낮아지니 보험사는 더 정확하게 적립할 수 있다
    오해: 평균이 낮아진 것은 비싼 고객을 지웠기 때문입니다. 실제 고객은 여전히 비쌉니다(과소 추정 30.2%).

해설 전체 1,337명 기준 139명 중 97.8%가 흡연자입니다. 학습 데이터에서 지우면(119명) 최종 모델의 시험 고액 10% MAE 가 $3,612 에서 $14,379 로 약 4배가 됩니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

문제 2

Q2. 상한 고정(윈저라이징)은 행을 지우지 않고 $33,240 위를 $33,240 으로 바꿉니다. 이 방법의 문제는?

  1. 행을 지우지 않으니 문제없다
    오해: 행은 남아도 정답(목표값)을 고쳤습니다. 모델은 $33,240 위의 금액을 배울 수 없습니다.
  2. 모델이 상한 위 금액을 배울 수 없어 고액 고객을 체계적으로 낮게 부른다 ✔ 정답
  3. 학습이 느려진다
    오해: 속도 문제는 없습니다. 문제는 고액 오차입니다.

해설 최종 모델 기준 고액 10% MAE 가 그대로 둘 때 $3,612, 상한 고정 시 $10,120 입니다. 평균 편향도 −$15 → −$971 로 낮게 부릅니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

문제 3

Q3. 최종 모델을 로그 금액으로 학습하고 exp 로 되돌렸더니 MAE 는 $2,470 → $2,139 로 줄었지만 과소 추정은 19.4% → 24.3% 로 늘었습니다. 올바른 해석은?

  1. MAE 가 줄었으니 무조건 로그가 낫다
    오해: 고액 MAE($3,612 → $4,635)와 평균 편향(−$533)이 나빠졌습니다. 숫자 하나로 고르지 않습니다.
  2. 되돌린 예측은 평균보다 중앙값 쪽이라, 전형적인 고객은 잘 맞히지만 평균적으로 낮게 부른다 ✔ 정답
  3. 로그 변환은 행을 지우는 것과 같다
    오해: 로그는 행도 금액도 그대로 두고 학습할 때 눈금만 바꿉니다.

해설 exp(로그 평균) = $8,955 는 평균 $13,279 보다 중앙값 $9,386 에 가깝습니다. 그래서 MAE 는 좋아지고 합계(적립금)는 모자랍니다. 2부에서 보정합니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

강의 멘트

중복

도입 오늘은 같은 기록이 두 번 들어간 행부터 찾습니다.

핵심 핵심: 중복을 남기면 같은 사람이 학습과 시험에 동시에 들어갈 수 있다(누수). 그래서 1행만 뺀다.

흔한 오해 흔한 오해: “1행이라 상관없다”. 이번 나누기에서는 둘 다 학습으로 갔지만, 나누기가 바뀌면(2부 5-Fold) 갈라질 수 있다.

정리 정리: 오류가 분명한 행만, 이유와 행 수를 밝히고 뺀다.

이상치 탐지

도입 다이얼을 돌리기 전에, k = 1.5 에서 몇 명이 걸릴지 예상하게 합니다.

핵심 핵심: 139명이 걸리고 그중 97.8%가 흡연자. 세기와 지우기는 다른 일이다.

흔한 오해 흔한 오해: “IQR 밖 = 오류”. 의료비 $63,770, BMI 53 은 모두 가능한 값이다.

정리 정리: 이상치를 지우면 1편의 숨은 열쇠(흡연)를 함께 지운다.

처리 비교

도입 같은 모델, 같은 시험 268명. 학습 데이터 처리만 바꿉니다.

핵심 핵심: 최종 모델 고액 MAE — 그대로 $3,612, 상한 고정 $10,120, 삭제 $14,379.

흔한 오해 흔한 오해: “평균이 깔끔해졌으니 좋아졌다”(머니로보). 시험의 실제 고객은 여전히 비싸다.

정리 정리: 처리는 학습에만, 평가는 손대지 않은 시험에서. 목표값은 자르지 않는다.

로그 변환

도입 로그 버튼으로 분포가 대칭이 되는 것을 먼저 봅니다(왜도 1.52 → −0.09).

핵심 핵심: 로그는 행도 금액도 지키면서 꼬리를 접는다. 예측은 exp 로 되돌려 달러로 잰다.

흔한 오해 흔한 오해: “MAE 가 줄었으니 로그가 무조건 낫다”. 과소 추정 24.3%, 편향 −$533.

정리 정리: 되돌린 값은 중앙값 쪽. 보정은 2부 3·4편.

문제 2

Q2. 선형 회귀의 R² 는 0.748, 최종 모델(GBM)은 0.860 입니다. 고액 10% MAE 는 $8,151 과 $3,612 입니다. 선형 회귀가 고액 고객에게 약한 가장 큰 이유는?

  1. 특성을 표준화했기 때문
    오해: 표준화는 계수의 단위만 바꿉니다. 예측은 같습니다.
  2. 흡연 효과를 모든 BMI 에 같은 금액으로 더하는 직선이라, ‘흡연자이면서 비만’에서 따로 뛰는 금액을 그리지 못한다 ✔ 정답
  3. 학습 데이터가 너무 적어서
    오해: 같은 1,069명으로 GBM 은 고액 MAE $3,612 를 냅니다.

해설 선형 계수는 흡연 +$9,686(표준화 1단위), BMI +$1,865 처럼 따로 더해집니다. 흡연 × 비만 띠(평균 $41,558)는 두 효과의 곱처럼 움직여 직선으로는 못 그립니다. 2부에서 상호작용 특성을 더하면 이 차이가 줄어듭니다.

핵심 핵심: 학생 나무는 실제값이 아니라 선생님(GBM)의 예측을 배운다.

흔한 오해 흔한 오해: “대리모델 = 원 모델의 요약이라 정확도도 같다”. 충실도와 정확도는 다른 숫자다.

정리 정리: 충실도 · 정확도 · 읽기 쉬움 세 가지를 함께 본다.

잎 수 다이얼

도입 잎 2개부터 올려 보며 충실도 막대를 봅니다.

핵심 핵심: 잎 6개에서 학습 CV 충실도가 0.95 를 처음 넘는다.

흔한 오해 흔한 오해: “시험 충실도가 가장 높은 잎 수를 고른다”. 그것은 누수다.

정리 정리: 종이 한 장 목표 + 학습 CV 기준으로 정한다.

규칙표

도입 규칙표 첫 줄을 소리 내어 읽게 합니다.

핵심 핵심: 첫 질문 흡연 여부 = 1편의 숨은 열쇠. 흡연자는 BMI 30 근처에서 다시 갈린다.

흔한 오해 흔한 오해: “흡연자는 가입 거절”. 규칙표는 금액만 정한다.

정리 정리: 이 규칙표는 성별 · 지역을 쓰지 않는다. 원 모델은 쓴다 → 6편에서 센다.

직접 나무와 비교

도입 대리 나무가 직접 배운 나무보다 꼭 정확할까요?

핵심 핵심: 이 데이터에서는 MAE 가 거의 같다. 고액 MAE 는 잎 7개 이상에서 대리가 작다.

흔한 오해 흔한 오해: “대리모델은 늘 더 정확하다”.

정리 정리: 대리모델의 목적은 원 모델과 같은 말을 하는 것.

문제 1

Q1. 이 편이 원 모델(GBM)을 서버에 올리는 대신 규칙표 앱을 고른 가장 큰 이유는?

  1. 규칙표가 원 모델보다 정확해서
    오해: MAE 는 규칙표 $3,113, 원 모델 $2,470 로 원 모델이 더 정확합니다.
  2. 상담 창구에 파이썬 · 서버가 없고, 종이 기준서와 앱이 같은 규칙을 써야 사람이 확인할 수 있어서 ✔ 정답
  3. 원 모델은 JS 로 옮길 수 없어서
    오해: 옮길 수 있습니다(2부 4편). 다만 파일이 크고 사람이 따라 읽을 수 없습니다.

해설 규칙표 앱은 HTML 한 장 + 규칙 JSON 으로 인터넷 없이 동작하고, 충실도 R² 0.961 을 대가로 받아들였습니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

문제 2

Q2. ‘시험 268명 일괄 검증’에서 불일치 0명이 뜻하는 것은?

  1. 규칙표가 실제 의료비를 268명 모두 정확히 맞혔다
    오해: 실제값과의 비교가 아니라 노트북(sklearn 대리모델)과의 비교입니다.
  2. 원 모델과 규칙표가 같다
    오해: 원 모델과는 충실도 0.961 만큼 다릅니다.
  3. 페이지 안의 JS 계산이 노트북의 대리모델 예측과 모든 고객에서 같다(배포 과정에서 규칙이 빠지거나 바뀌지 않았다) ✔ 정답

해설 f6.py 에서도 같은 대조를 했습니다: 불일치 0명, 최대 차이 $0.0036 (JSON 에 소수 둘째 자리까지 저장했기 때문).

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

문제 3

Q3. 규칙표 견적에 여유분 +0.06 를 곱하자 비용이 줄었지만, $10,000 넘게 적게 잡은 사람은 17명 그대로입니다. 올바른 해석은?

  1. 여유분을 더 키우면 해결된다
    오해: +60% 를 얹어도 실제가 견적의 몇 배인 고객은 남습니다. 대신 나머지 고객의 견적이 폭발합니다.
  2. 여유분은 평균적인 부족분을 메울 뿐, 데이터 밖의 사정으로 생긴 큰 청구는 따로(재보험 · 준비금) 다뤄야 한다 ✔ 정답
  3. 그 사람들을 데이터에서 지워야 한다
    오해: 목표값은 지우거나 자르지 않습니다. 꼬리는 오류가 아니라 사실입니다(2편).

해설 1인당 비용 $6,394 → $6,142, 적게 잡은 비율 36.2% → 26.5%. 큰 청구의 꼬리는 2부 5편(재보험 대형사고)에서 다시 봅니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

문제 4

Q4. 성별을 반대로 바꿨을 때 견적이 바뀐 사람이 규칙표 0명, 원 모델 268명입니다. 이 결과로 할 수 있는 말은?

  1. 규칙표는 성별을 견적에 쓰지 않는다는 것을 실제로 확인했고, 원 모델은 성별이 견적을 움직인다는 것을 확인했다 ✔ 정답
  2. 원 모델이 성별을 차별한다고 단정할 수 있다
    오해: 바뀐 금액(최대 $1,360)과 이유, 규정을 함께 봐야 합니다. 숫자는 점검의 출발점입니다.
  3. 규칙표는 모든 면에서 공정하다
    오해: 나이 · BMI · 흡연이 다른 집단과 얽혀 있을 수 있어, 성별 0명만으로 공정하다고 할 수 없습니다.

해설 지역을 모두 northeast 로 바꾸면 규칙표 0명, 원 모델 159명(최대 $1,153)의 견적이 바뀝니다.

배점 2점 · 정답 + 이유 한 문장 = 2점, 정답만 = 1점, 오답이어도 핵심 이유를 말하면 1점

강의 가이드라인

  • 도입 5분: 배포 방식 네 가지 표를 보여 주고 “우리 회사라면?”을 묻는다. 정답은 하나가 아니다.
  • 시연 10분: 견적 앱에 학생 두세 명의 가상 고객을 넣어 경로를 소리 내어 읽는다. 나이 70 · BMI 60 을 넣어 범위 밖 경고를 보여 준다.
  • 검증 5분: ‘검증 실행’ → 불일치 0. 대조 상대가 실제값이 아니라 노트북이라는 점을 강조한다.
  • 토론 10분: $10,000 넘게 적게 잡은 사람들을 보며 “여유분으로 메울 수 있는가?”를 묻고, 2부 5편(재보험 · 대형사고)으로 잇는다.
  • 마무리: 초파리 질문 “한 번 잰 숫자, 운 아니에요?” → 2부(실전)로 넘어간다.

배포 방식

도입 상담 창구에 파이썬이 없다면, 모델을 어떻게 내보낼까요?

핵심 핵심: 서버 API · 원 모델 JS 이식 · 규칙표 앱 · 종이. 이 편은 규칙표 앱.

흔한 오해 흔한 오해: “가장 정확한 모델을 그대로 내보내는 게 늘 정답”. 현장 제약과 확인 가능성도 기준이다.

정리 정리: 규칙표 앱은 충실도 0.961 을 대가로 HTML 한 장 · 인터넷 없음 · 사람이 확인 가능.

견적 앱

도입 흡연자 45세 BMI 31 을 넣고 경로를 같이 읽습니다.

핵심 핵심: 견적 = 잎 금액, 적립 권장액 = 견적 × (1 +0.06).

흔한 오해 흔한 오해: “성별을 바꾸면 견적이 바뀐다”. 이 규칙표에는 성별 질문이 없다.

정리 정리: 범위 밖 입력(나이 70)은 가장 가까운 잎 금액을 그대로 준다 → 경고를 띄운다.

일괄 검증

도입 버튼을 누르기 전에 불일치가 몇 명일지 예측하게 합니다.

핵심 핵심: 불일치 0명 = 배포 과정에서 규칙이 빠지지 않았다.

흔한 오해 흔한 오해: “불일치 0 = 실제값도 다 맞힘”. 대조 상대는 노트북 대리모델이다.

정리 정리: $10,000 넘게 적게 잡은 17명은 여유분으로도 안 메워진다 → 꼬리는 따로.

도입 성별만 바꾸면 견적이 바뀌는 사람이 몇 명일까요?

정리 정리: ‘안 쓴다’는 말 대신 ‘바꿔 봤더니 몇 명’이라는 숫자로 보고한다.
